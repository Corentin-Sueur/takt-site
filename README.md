# takt.corentinsueur.com

The site for Takt, a free rowing app for Android: manual, screenshots and the APK.

Issues here are the public tracker for the app: open a [bug report](../../issues/new?template=bug.yml) or a [feature request](../../issues/new?template=feature.yml).

The site is generated and force-pushed from a private repository; edit it there, not here.
